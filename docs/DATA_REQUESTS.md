# Запросы на доступ к данным (шаблоны)

Нужно отправлять от юридического лица или ФОП (реквизиты — в `OPERATOR_NAME` / `OPERATOR_DETAILS`).
Цены и условия актуальны только в ответе организации; статья 2016 года (постановление КМУ № 260 от 25.03.2016) даёт лишь рамку: доступ по договору с администратором реестра, расширенные сведения платные.

## 1. ГСЦ МВС — доступ к Единому государственному реестру транспортных средств

Кому: Главный сервисный центр МВС (hsc.gov.ua), через раздел «Публичная информация» / запрос на публичную информацию.

> Просим сообщить порядок и условия заключения договора на получение сведений из Единого государственного реестра МВС о транспортных средствах (постановление КМУ № 260 от 25.03.2016) в электронной форме для юридического лица (ФОП):
> 1. Какие сведения доступны по критерию поиска «VIN» и «номерной знак» (марка, модель, год, цвет, топливо, объём/мощность двигателя, количество владельцев, ограничения, техосмотр, полис ОСЦПВ, количество ДТП) и в каком формате (API, пакетные файлы, выписки)?
> 2. Тарифы за запись и за пакетный доступ, условия оплаты.
> 3. Требования к заявителю и документы, срок заключения договора.
> 4. Допустимо ли отображение полученных сведений о транспортном средстве (без персональных данных владельцев) в платном отчёте для пользователей сайта; требуются ли отдельные разрешения?
> 5. Есть ли ограничения по хранению сведений и обязательное уведомление владельцев о запросах?

## 2. МТСБУ — страховая история и полисы ОСЦПВ

Кому: Моторное (транспортное) страховое бюро Украины (mtsbu.ua), департамент информационных систем.

> Нам известно, что у МТСБУ есть REST/SOAP-сервисы электронного полиса (policy-doc.mtsbu.ua, документация ПЕП: REST `GetStatus/ByPlateNum`, `GetStatus/ByCode`, `GetVehicle/ByVIN`, а также `GetHistory/ByVIN` v6 — история полисов и страховых случаев, бонус-малус; аутентификация HTTP Basic, для read-сервисов без VPN). Просим сообщить порядок подключения к этим read-сервисам для организации, не являющейся страховой компанией (веб-сервис проверки автомобилей), условия договора, тестовую среду и тарифы.
>
> Просим также сообщить условия получения (по договору, через API или пакетно) сведений Единой централизованной базы данных (ЕЦБД) об автомобильных полисах ОСЦПВ и страховых случаях по VIN/номерному знаку:
> 1. Перечень данных и формат доступа, тарифы.
> 2. Требования к заявителю и срок заключения договора.
> 3. Можно ли показывать эти сведения в отчёте для покупателей автомобиля.

## 3. Вопросы юристу (до запуска платного режима)
- Оферта и политика конфиденциальности: роль оператора, срок хранения запросов (сейчас 90 дней).
- Право отображать данные Copart/IAAI и архивов аукционов в платном отчёте (условия поставщика API и аукциона).
- Данные МВС о VIN/номере: публикация без ПИБ владельцев (колонка `person` не сохраняется).
- Оформление ФОП/ТОВ и приём платежей через Stripe из Украины.
