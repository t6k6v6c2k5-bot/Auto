# VINScope — проверка авто по VIN и госномеру

Сайт на Node 22 без внешних зависимостей (встроенный SQLite), языки uk / ru / en, деплой на Railway.

## Что работает сейчас (реальные открытые данные)
| Раздел | Источник |
|---|---|
| Розыск по VIN и номеру | Нацполиция Украины, data.gov.ua (79 тыс. записей, обновление раз в 6 часов) |
| История регистраций в Украине: ввоз, смены владельцев, номера, снятие с учёта | реестр ТС МВС, data.gov.ua (2021–2026, ~11 млн операций, загружается в фоне) |
| История по госномеру для старых записей | архивы МВС 2013–2020 (опубликованы без VIN, ~13 млн операций): поиск по номеру, записи сгруппированы по авто |
| Расшифровка VIN, отзывные кампании, жалобы, краш-тесты | NHTSA (США; для европейских VIN разбор частичный, выводы из него не делаются) |
| Risk Score 0–100 с объяснением, сверка VIN с реестром | считается из данных выше |
| Фото модели | Wikipedia (иллюстрация модели, подписана; для другого поколения показывается силуэт) |

**Режим запуска:** пока не задан `STRIPE_SECRET_KEY`, всё бесплатно и без регистрации, страница проверки — это и есть полный отчёт (печать и постоянная ссылка). Раздел «аукционы США» помечен «планируется», есть лист ожидания.

Где взять недостающие данные (Copart/IAAI, пробег, цены продажи, Европа): [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md).

## Платный режим
Задайте `STRIPE_SECRET_KEY` и `STRIPE_WEBHOOK_SECRET` (вебхук `POST /webhook/stripe`, событие `checkout.session.completed`). Тарифы в `src/config.js` (сейчас $5,99 / $14,99 за 3 / $39 за 10). Что включается: тизер на странице проверки, оформление, отчёт по токену, пакеты по коду, **автовозврат**, если по VIN нет данных ни в одном источнике. Заказ с неудавшимся возвратом получает статус `refund_failed` и виден в `/admin`.

## Переменные окружения (Railway → Variables)
| Переменная | Назначение |
|---|---|
| `BASE_URL` | `https://ваш-домен`: canonical, sitemap, ссылки Stripe (без неё берётся Host/`RAILWAY_PUBLIC_DOMAIN`) |
| `DB_PATH` | заказы и кэш; **подключите Volume**, напр. `/data/vinscope.db` (реестр кладётся рядом: `registry.db`) |
| `SUPPORT_EMAIL` | показывается в футере и оферте; пока пусто — не показывается |
| `OPERATOR_NAME`, `OPERATOR_DETAILS` | ФОП/ТОВ, ЄДРПОУ, адрес — в оферту и футер (нужны до приёма платежей) |
| `ADMIN_KEY` | пароль для `/admin` (HTTP Basic, любое имя пользователя), минимум 16 символов |
| `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` | включают платный режим |
| `MARKETCHECK_API_KEY` | **США и Канада:** история онлайн-объявлений по VIN (цены, пробег, дилеры, даты) через MarketCheck, около $0,006 за запрос. Включает детектор скрутки пробега. Ответы кэшируются 7 суток (пустые — сутки) |
| `USA_DAILY_LIMIT` (500) | потолок платных запросов в сутки: защита бюджета |
| `REPORT_API_URL`, `REPORT_API_KEY` | любой другой платный поставщик (аукционный): `GET ?vin=&plan=` → `{found, source, sections:{title, odometer[], auction[]}}`; аукционы показываются таблицей |
| `REGISTRY_FROM_YEAR` (2013), `REGISTRY_MAX_GB` (3.5), `REGISTRY_DISABLED=1` | параметры загрузки реестра МВС (до 2021 — архивы только по номеру) |
| `PLAUSIBLE_DOMAIN` | аналитика Plausible (события: search, waitlist, share, print, unlock) |

## Безопасность и приватность
CSP, HSTS, `X-Robots-Tag: noindex` на результатах; лимиты запросов по IP из конца `X-Forwarded-For`; подпись вебхука Stripe и сверка суммы; атомарная смена статуса заказа; админка по Basic-авторизации; токены отчётов 128 бит; запросы (VIN/номер) хранятся 90 дней; колонка «физлицо/юрлицо» из реестра не сохраняется.

## Запуск и тесты
