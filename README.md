# VINScope — проверка авто по VIN и госномеру

Сайт на Node 22 без внешних зависимостей (встроенный SQLite), языки uk / ru / en, деплой на Railway.

## Что работает сейчас (реальные открытые данные)
| Раздел | Источник |
|---|---|
| Розыск по VIN и номеру | Нацполиция Украины, data.gov.ua (79 тыс. записей, обновление раз в 6 часов) |
| История регистраций в Украине: ввоз, смены владельцев, номера, снятие с учёта | реестр ТС МВС, data.gov.ua (2021–2026, ~11 млн операций, загружается в фоне) |
| История по госномеру для старых записей | архивы МВС 2013–2020 (опубликованы без VIN, ~13 млн операций): поиск по номеру, записи сгруппированы по авто |
| Расшифровка VIN, отзывные кампании, жалобы, краш-тесты | NHTSA (США; для европейских VIN разбор частичный, выводы из него не делаются) |
| Risk Score 0–100 с объяснением, сверка VIN с реестром | считается из данных выше |
| Нидерланды: данные по номеру (техосмотр, страховка, экспорт, логичность пробега) | RDW open data, opendata.rdw.nl |
| Фото модели | Wikipedia (иллюстрация модели, подписана; для другого поколения показывается силуэт) |

**Режим запуска:** пока не задан `STRIPE_SECRET_KEY`, всё бесплатно и без регистрации, страница проверки — это и есть полный отчёт (печать и постоянная ссылка). Раздел «аукционы США» помечен «планируется», есть лист ожидания.

Где взять недостающие данные (Copart/IAAI, пробег, цены продажи, Европа): [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md).

## Платный режим
Задайте `STRIPE_SECRET_KEY` и `STRIPE_WEBHOOK_SECRET` (вебхук `POST /webhook/stripe`, событие `checkout.session.completed`). Тарифы в `src/config.js` (сейчас 99 ₴ / 249 ₴ за 3 / 690 ₴ за 10, валюта UAH). Что включается: тизер на странице проверки, оформление, отчёт по токену, пакеты по коду, **автовозврат**, если по VIN нет данных ни в одном источнике. Заказ с неудавшимся возвратом получает статус `refund_failed` и виден в `/admin`.

## Переменные окружения (Railway → Variables)
| Переменная | Назначение |
|---|---|
| `BASE_URL` | `https://ваш-домен`: canonical, sitemap, ссылки Stripe (без неё берётся Host/`RAILWAY_PUBLIC_DOMAIN`) |
| `DB_PATH` | заказы и кэш; **подключите Volume**, напр. `/data/vinscope.db` (реестр кладётся рядом: `registry.db`) |
| `SUPPORT_EMAIL` | показывается в футере и оферте; пока пусто — не показывается |
| `OPERATOR_NAME`, `OPERATOR_DETAILS` | ФОП/ТОВ, ЄДРПОУ, адрес — в оферту и футер (нужны до приёма платежей) |
| `ADMIN_KEY` | пароль для `/admin` (HTTP Basic, любое имя пользователя), минимум 16 символов |
| `MONO_TOKEN` | **Оплата через monobank (основная):** X-Token из web.monobank.ua (бизнес-кабинет) или тестовый с api.monobank.ua. Вебхук: `POST /webhook/mono` (адрес передаётся в счёте автоматически, подпись ECDSA проверяется). Автовозврат — отмена оплаты |
| `LEMON_API_KEY`, `LEMON_STORE_ID`, `LEMON_VARIANT_ID`, `LEMON_SIGNING_SECRET`, `LEMON_CURRENCY` (USD) | **Оплата без ФОП (временно):** Lemon Squeezy продаёт от своего имени (Merchant of Record), выплаты через PayPal. Цена 99 ₴ пересчитывается в валюту магазина по курсу НБУ. Вебхук: `POST /webhook/lemon`, событие `order_created`. Когда задан `MONO_TOKEN`, используется monobank |
| `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` | альтернатива: оплата через Stripe (используется, если `MONO_TOKEN` не задан) |
| `MARKETCHECK_API_KEY` | **США и Канада:** история онлайн-объявлений по VIN (цены, пробег, дилеры, даты) через MarketCheck, около $0,006 за запрос. Включает детектор скрутки пробега. Ответы кэшируются 7 суток (пустые — сутки) |
| `APIBARA_API_KEY` | **Аукционы США (Copart/IAAI):** лоты по VIN, повреждения, цена продажи, оценка стоимости, пробег, фото лота (отдаются через `/api/lotimg`). Бесплатный тариф Test: 100 запросов в месяц, без карты (apibara.tech). Ответы кэшируются 7 суток |
| `USA_DAILY_LIMIT` (500) | потолок платных запросов в сутки: защита бюджета |
| `REPORT_API_URL`, `REPORT_API_KEY` | любой другой платный поставщик (аукционный): `GET ?vin=&plan=` → `{found, source, sections:{title, odometer[], auction[]}}`; аукционы показываются таблицей |
| `REGISTRY_FROM_YEAR` (2013), `REGISTRY_MAX_GB` (3.5), `REGISTRY_DISABLED=1` | параметры загрузки реестра МВС (до 2021 — архивы только по номеру) |
| `MTSBU_READ_URL`, `MTSBU_TOKEN` | **Страхование ОСЦПВ напрямую из МТСБУ** (read-сервисы «Поліс Онлайн», policy-doc.mtsbu.ua): `GetStatus/ByPlateNum` (действующий полис, страховщик, лимиты) и `GetHistory/ByVIN` (история полисов, страховые случаи, бонус-малус). Токен Basic выдаёт МТСБУ; тестовый хост `https://policy-read-test.mtsbu.ua`. Без этих переменных раздел скрыт |
| `INSURANCE_API_URL`, `INSURANCE_API_KEY` | **Проверка ОСЦПВ:** `GET ?vin=&plate=&date=` + `Bearer` → `{status: active/none/pending, insurer, from, to, kind}`. Подключается после договора с МТСБУ (публичная форма МТСБУ защищена капчей, открытого API нет) или у партнёра-поставщика; без этих переменных раздел скрыт |
| `RIA_API_KEY` | **Рыночная цена в Украине:** ключ открытого API объявлений (developers.ria.com). Бесплатно, ограничения: пакет ключа — 1000 запросов всего, метод средней цены — 10 в час; потолки `RIA_PRICE_HOURLY` (8), `RIA_HOURLY_LIMIT` (30), `RIA_DAILY_LIMIT` (60); цены кэшируются на 7 дней, боты данные не запрашивают; при ответе об превышении лимита запросы приостанавливаются на 15 минут; результаты кэшируются на сутки. Условия использования данных (атрибуция, публикация) уточнить в договоре сервиса. |
| `SEARCH_API_KEY` | **Упоминания в сети:** ключ Brave Search API (api.search.brave.com, $5 за 1000 запросов, ~$5 бесплатно в месяц). Ищется точный VIN/номер, сохраняются только домен, заголовок без контактов, тип и дата. Кэш 14 суток (пустые — 3 суток); раздел скрыт, пока ключа нет |
| `SEARCH_DAILY_LIMIT` (300) | потолок поисковых запросов в сутки |
| `RDW_BASE` | (тесты) база API RDW |
| `PLAUSIBLE_DOMAIN` | аналитика Plausible (события: search, waitlist, share, print, unlock) |

## Безопасность и приватность
CSP, HSTS, `X-Robots-Tag: noindex` на результатах; лимиты запросов по IP из конца `X-Forwarded-For`; подпись вебхука Stripe и сверка суммы; атомарная смена статуса заказа; админка по Basic-авторизации; токены отчётов 128 бит; запросы (VIN/номер) хранятся 90 дней; колонка «физлицо/юрлицо» из реестра не сохраняется.

## Запуск и тесты
